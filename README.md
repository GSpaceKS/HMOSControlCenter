## 反馈

遇到问题或有建议，欢迎通过 [Issues](https://github.com/GSpaceKS/HMOSControlCenter/issues) 反馈。为了便于排查，请尽量附上以下信息：

- 手机型号（如 Mate 40 Pro+）
- 系统版本（如 HarmonyOS 4.2.0）
- 使用的模式（普通模式 / Shizuku 模式）
- 问题描述与复现步骤
- 相关截图或录屏（如有）

> 请先搜索是否已有相同 Issue，避免重复提交。
